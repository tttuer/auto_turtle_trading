# Auto Turtle Trading Bot 🐢📊

한국투자증권(KIS) OpenAPI와 Python(`uv`)을 활용하여 리눅스/Mac 환경에서 24시간 돌아가는 **장기 복리형 자동매매 봇**입니다.
코스피 200 주요 섹터(반도체, 자동차, 금융 등)별 시가총액 상위 종목을 매일 동적으로 추출하고, **버핏/피터 린치식 Quality-GARP 코어 전략**을 중심으로 운용합니다. 터틀 트레이딩은 보조 추세 전략으로만 사용하며, 단기 평균 회귀 전략은 과도한 회전율을 막기 위해 기본 비활성화되어 있습니다.

---

## 📈 매매 전략

### 전략 1: Quality-GARP 코어 (Buffett + Peter Lynch) — 자산의 75%

좋은 기업을 합리적인 가격에 사서 오래 보유하는 장기 코어 전략입니다. OpenDART 공식 재무제표와 pykrx 일별 밸류에이션 데이터를 사용해 ROE, 마진, 성장률, 부채비율, PER/PBR 등을 점수화합니다. API 키가 없거나 데이터 조회가 실패하면 수동 퀄리티 점수와 가격/추세 기반 대용 지표로 폴백합니다.

- **진입**: 퀄리티 점수 상위 종목 중 52주 고점 대비 충분히 할인되어 있고, 6개월 추세가 구조적으로 망가지지 않은 종목만 40%/30%/30%로 분할 매수
- **재무 필터**: ROE, 영업이익률, 매출/이익 성장률, 부채비율, PER/PBR, 배당수익률 반영
- **GARP 필터**: PER과 성장률을 함께 보며 PEG가 낮은 기업은 가점, 성장 없이 비싼 기업은 감점
- **타이밍 필터**: RSI, MACD, 볼린저밴드, 20/60/120/200일 이동평균으로 과매도 후 회복과 추세 안착을 확인
- **매수 빈도 제한**: 하루 신규 매수 최대 1개
- **분산 제한**: 최대 8개 코어 포지션, 종목당 최대 12%
- **최소 보유기간**: 60 거래일
- **청산**: 기술적 약화는 30% 비중 축소, 재무 훼손/장기 추세 붕괴/큰 낙폭은 70%까지 강한 축소

### 전략 2: 터틀 트레이딩 보조 Sleeve — 자산의 5%

추세가 강한 장에서 일부 수익 기회를 포착하는 보조 전략입니다. 코어 포지션과 같은 종목을 중복 매수하지 않습니다.

- **진입**: 최근 20일 최고가 돌파 시 매수 (1 Unit)
- **피라미딩(불타기)**: 진입 후 가격이 `0.5N(변동성)` 상승할 때마다 1 Unit씩 추가 매수 (최대 4 Unit)
- **손절매**: 마지막 진입가 대비 `2N` 하락 시 전량 매도
- **청산**: 최근 10일 최저가 이탈 시 전량 매도
- **자금 관리**: 총 자산의 10%를 기준으로, 1% Risk에 맞춰 매일 1 Unit 수량을 동적으로 재계산

### 전략 3: 평균 회귀 (Mean Reversion) — 기본 비활성화

횡보장·약세장에서 낙폭과대 종목의 반등을 포착하는 단기 전략입니다. 다만 매매 빈도와 회전율이 높아질 수 있어 현재는 `Config.ENABLE_MEAN_REVERSION = False`로 비활성화되어 있습니다.

### 전략 간 상보성

| 시장 상황 | Quality-GARP 코어 | 터틀 보조 | 평균 회귀 |
|-----------|-------------------|-----------|-----------|
| 강한 추세장 | 좋은 기업을 계속 보유 | 일부 추세 수익 추가 | 기본 OFF |
| 횡보장 | 잦은 매매 억제 | 신호 적음 | 기본 OFF |
| 약세장 | 현금 10%와 보수적 신규 매수 | 손절로 방어 | 기본 OFF |

### 공통 안전장치

- **현금 보호 (부분 매수)**: 매수 신호 발생 시 주문 가능 예수금(D+2)이 부족할 경우 남은 현금 한도 내에서 수량 자동 조절
- **중복 포지션 방지**: 코어 포지션 보유 종목은 터틀/평균회귀 신규 매수 대상에서 제외
- **회전율 제한**: 코어 전략은 하루 1회, 장 후반에만 평가하며 하루 신규 매수 수를 제한
- **API 레이트 리밋 방어**: 로컬에서 실시간 가상 예수금을 추적하여 서버 과부하 방지

## 🚀 설치 및 실행 방법

### 1. 사전 준비

이 프로젝트는 매우 빠르고 가벼운 파이썬 패키지 매니저인 `uv`를 사용합니다.
- [uv 설치 가이드](https://docs.astral.sh/uv/)에 따라 `uv`를 먼저 설치해 주세요.

### 2. 저장소 복제 (Clone)

```bash
git clone https://github.com/tttuer/auto_turtle_trading.git
cd auto_turtle_trading
```

### 3. 환경 변수 세팅 (API Key)

`.env.example` 파일을 복사하여 `.env` 파일을 생성하고, 한국투자증권에서 발급받은 API 키를 입력합니다.
> **주의**: `.env` 파일은 Github에 올라가지 않도록 `.gitignore`에 등록되어 있습니다.

```bash
cp .env.example .env
nano .env
```

```dotenv
# .env 파일 예시
KIS_APP_KEY=본인의_앱키
KIS_APP_SECRET=본인의_앱시크릿
KIS_ACCOUNT_NO=12345678-01
DART_API_KEY=OpenDART_인증키
FINANCIAL_CACHE_DB=financial_cache.db
MODE=VIRTUAL  # 실전 투자는 REAL 로 변경

# 텔레그램 알림 (선택)
TELEGRAM_BOT_TOKEN=봇_토큰
TELEGRAM_CHAT_ID=챗_아이디
```

### 4. 프로그램 실행

```bash
uv run main.py
```

### 5. 24시간 백그라운드 무중단 실행

**🔹 리눅스 / Mac (nohup 방식)**

```bash
nohup uv run main.py > bot.log 2>&1 &
```

- 종료: `ps -ef | grep main.py`로 PID 확인 후 `kill -9 PID`

**🔹 윈도우 (Windows)**

```powershell
uv run pythonw main.py
```

- 종료: 작업 관리자(`Ctrl + Shift + Esc`)에서 `pythonw.exe` 프로세스 종료

## 📂 주요 파일 설명

| 파일 | 설명 |
|------|------|
| `main.py` | 프로그램 진입점. 스케줄러 및 실시간 웹소켓(현재가 수신) 데몬 |
| `financial_data_provider.py` | OpenDART 재무제표 및 pykrx 밸류에이션 데이터 수집/캐시 |
| `quality_garp_strategy.py` | 버핏/피터 린치식 Quality-GARP 장기 코어 전략 |
| `strategy.py` | 터틀 트레이딩 핵심 알고리즘 (N값, Unit 사이즈, 피라미딩/손절/청산) |
| `mean_reversion_strategy.py` | 평균 회귀 전략 (기본 비활성화, RSI + 볼린저 밴드) |
| `kis_api.py` | 한국투자증권 REST API 통신 모듈 |

| `core_positions.json` | 코어 전략 포지션 상태 저장 (봇 재시작 시 복원) |
| `positions.json` | 터틀 전략 포지션 상태 저장 (봇 재시작 시 복원) |
| `mr_positions.json` | 평균 회귀 전략 포지션 상태 저장 (봇 재시작 시 복원) |
| `trade_history.csv` | 전체 매매 기록 (`strategy` 컬럼으로 전략별 성과 분리 분석 가능) |
| `balance_history.csv` | 매 1시간 계좌 잔고 추이 기록 |
| `financial_cache.db` | 재무 데이터 SQLite 캐시 (git 제외) |

## ⚠️ 주의사항

- **모의투자 운영 시간**: 모의투자 서버도 실제 주식 시장 시간(평일 09:00 ~ 15:30)과 동일하게 동작합니다. 장이 열리지 않는 밤이나 주말에는 가격 데이터가 수신되지 않습니다.
- **API 호출 제한 (TPS)**: 한국투자증권 API는 초당 호출 횟수 제한이 있습니다. 에러(`EGW00133` 등)가 발생하면 1분 뒤에 다시 실행해 주세요.
- **초기화 시간**: 두 전략이 각각 40개 종목의 지표를 계산하므로, 봇 시작 시 초기화에 약 80초가 소요됩니다. 장 시작(09:00) 전 08:30에 자동 재초기화됩니다.
- **재무 데이터 최신성**: OpenDART 재무제표 캐시는 1일, pykrx 밸류에이션 캐시는 1일 단위로 갱신됩니다. OpenDART 키가 없으면 재무 점수는 자동으로 가격/수동 점수 기반으로 폴백합니다.
- **기존 거래 기록**: `trade_history.csv`가 이미 존재할 경우, `strategy` 컬럼이 추가된 새 형식과 맞지 않을 수 있습니다. 처음 전략 변경 후 실행 시 해당 파일을 삭제하거나 백업한 뒤 새로 시작하는 것을 권장합니다.
